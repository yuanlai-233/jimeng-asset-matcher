# v0.3.15 界面设计说明

普通页与画布共用小巧、柔弹的深色胶囊控件。整体从约 332 × 42px 缩到约 252 × 34px；按钮从 114 × 32px 缩到 88 × 28px。用上传和星形小图标替代圆圈编号，保留“自动上传”“自动匹配”全称。上传为深色次操作，匹配为柔白主操作，状态仍用文字和颜色共同表达。

按钮按下在 80ms 内轻压，松开约 440ms 回弹，悬停略微抬起。结果提示在约 460ms 内弹入、130ms 淡出；确认弹窗与首次说明使用同样的弹性节奏。动效仅在交互瞬间播放，系统设置减少动态效果时关闭缩放、位移和旋转动画。普通页和画布的外层定位不参与缩放，避免干扰原生编辑器几何识别。

悬停提示最多两行操作说明，延迟 420ms 出现，键盘聚焦即时显示；辅助描述仍保留完整两步顺序。长状态详情按可用视口高度滚动。结果提示最大宽度从 500px 改为 340px，移除“操作提示”“暂未完成”等重复标题，以实际消息和下一步为主体；结果提示存在时，控制条的悬停层暂时不显示。提示支持关闭；鼠标或键盘停留时暂停消失，更新消息不会被上一条提示的淡出计时误删。

确认卡最大宽度 350px、圆角 24px；首次说明宽度 460px，并受视口限制。保留首次说明只显示一次、上传与匹配分开点击、匹配时隐藏控制条等现有行为。
