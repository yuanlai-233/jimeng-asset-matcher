# Security Policy

This project is an unofficial helper for exact reference matching and automatic upload. It is not affiliated with, sponsored by, authorized by, approved by, or endorsed by Jimeng, Jianying, Dreamina, CapCut, or ByteDance. See [DISCLAIMER.md](DISCLAIMER.md).

## Supported version

Only the latest release is supported with security fixes.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting / Security Advisory feature for this repository. Do not open a public issue containing prompts, asset names, local paths, screenshots, account identifiers, or uploaded files.

For general security contact, email [cs_svip@163.com](mailto:cs_svip@163.com). Send the smallest redacted reproduction possible; do not attach private assets, complete prompts, local paths, account identifiers, cookies, tokens, or other credentials unless a secure follow-up channel has been agreed.

Include the extension version, browser version, affected target site, reproduction steps, and the smallest non-sensitive diagnostic information needed. Reports involving accidental file access, cross-task matching, duplicate upload, prompt mutation, or permission leakage are treated as high priority.
