# 隐私说明

生效日期：2026-09-10

“即梦素材一键匹配”是本地运行的浏览器扩展，没有开发者服务器、账号系统、统计、广告或遥测。

本项目是非官方开源辅助工具，与即梦、剪映、Dreamina、CapCut 或字节跳动不存在隶属、合作、授权、赞助、认可或背书关系。完整说明见 [DISCLAIMER.md](DISCLAIMER.md)。

## 扩展会读取什么

- 当前即梦 / Dreamina 创作框中的提示词，用于识别显式 `@完整素材名`。
- 用户主动选择的文件夹及子文件夹中的文件名，用于建立当前页面会话的本地索引。
- 只有与提示词中显式完整名称精确匹配的素材，才会读取为 `File` 并交给当前网页的原生上传入口。
- 当前网页原生素材菜单的可见名称和上传状态，用于完成匹配并防止重复操作。

## 什么会离开本机

插件本身不会向开发者或其他自建服务发送任何内容。用户点击“自动上传”后，命中的素材和其文件名会交给当前打开的即梦或 Dreamina 页面上传，并由该网站依据其自身条款和隐私政策处理。未命中的文件只检查文件名，不读取文件内容，也不会交给网页上传。

## 本地保存

- `chrome.storage.local` 只保存 `jimengOnboardingSeenV1: true`，表示首次使用说明已经看过。读取时同时兼容短暂使用过的 `jimengOnboardingSeenV2` 标记，避免升级后重复弹出。
- 文件夹句柄、目录索引、待匹配批次和已验证名称只保存在当前页面内存，刷新或关闭页面后失效。
- `v0.3.6` 及更早版本曾从内容脚本把目录句柄保存到目标网站 origin 的 IndexedDB。`v0.3.7` 不再这样做，并在启动时请求删除名为 `jimeng-asset-matcher` 的旧数据库。
- 刷新或关闭当前页面即可清除本次文件夹句柄与索引；按住 Shift 点击“自动上传”可在当前页面重新选择文件夹。

## 权限

- `storage`：只保存首次说明已读状态。
- `https://jimeng.jianying.com/*`：在即梦页面提供上传和匹配功能。
- `https://dreamina.capcut.com/*`：在 Dreamina 页面提供上传和匹配功能。

扩展不申请 Cookie、浏览历史、标签页、下载、身份、剪贴板或任意网站访问权限，也不包含远程运行脚本。

## 页面可见信息

新版普通视频页使用浏览器文件选择 API。兼容脚本只在用户点击“自动上传”且精确匹配素材后，临时把该次选择结果交给当前可见创作框；成功、失败、超时或用户打断时恢复原文件选择功能。临时 FileList 在交接后移除，不读取或保存额外文件，不新增网络服务或权限。

新画布自动上传只打开当前视频节点的“添加参考 → 上传参考内容”，临时交接已精确命中的素材，然后恢复文件选择接口。现有参考的替换入口和画布全局上传入口不作为目标。图片解码预检只处理本批命中的图片文件，解码后的位图立即释放。节点上传记录按当前页面路径和节点标识隔离，只存于内存。

匹配时，兼容脚本通过当前网页编辑器的选区接口同步光标，并在点击素材前再次核验原文及选区。不会构造素材标签或删除原有提示词。新画布的原生按钮若复用已有 @ 查询，会在确认原文和光标未变化后，通过编辑器事务追加一个临时 @，让网页原生候选只替换该字符；取消时仅清理插件拥有且仍可核验的临时字符。临时校验记录仅在当前页面内存中保存。

扩展会把状态提示和说明界面注入当前网页 DOM。公开提示不会显示本机根文件夹名、冲突文件的相对路径或未命中文件清单。素材名会在匹配状态中显示，因为这是功能所必需的信息；目标网页脚本理论上可以观察网页 DOM 中的这些状态文字。

## 删除数据

- 刷新或关闭当前页面，清除当前文件夹会话。
- 在浏览器扩展详情中清除扩展数据，可删除首次说明已读状态。
- 卸载扩展会删除扩展自身存储；目标网站已经接收的素材需在目标网站内自行删除。
