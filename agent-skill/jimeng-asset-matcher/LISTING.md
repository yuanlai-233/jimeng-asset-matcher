## 一句话简介

让 AI 帮你安装即梦素材匹配扩展，按提示词自动上传图片、视频和音频，一键补齐原生素材引用。

## 详细介绍

写好提示词，还要逐个上传素材、反复点开引用菜单？即梦素材一键匹配把这段操作整理成两步：自动上传，再自动匹配。

在提示词里写 `@完整素材名`，选择本地素材文件夹，扩展就会递归查找并上传对应的图片、视频和音频；随后点击自动匹配，在原文字后追加网页原生参考标签。同一文件重复引用只上传一份，每处引用分别绑定，适合多人物、多场景和混合媒体的视频创作。

这个 Skill 内置 v0.3.22 完整扩展源码、离线安装脚本和图文使用说明。AI 助手可以完成文件安装、解释命名规则和排查常见问题。安装脚本自动校验文件、准备固定安装目录，更新保留备份；本机 AI 有桌面操作工具时还可协助加载扩展。

支持即梦普通创作页与无限画布，并包含 Dreamina 站点适配。首次使用需要在桌面 Chrome 或 Edge 加载扩展；本包附操作截图。安装器需要 Python 3.9+，无 Python 可手动加载内置扩展。无需 API Key 或 npm 依赖。

这是独立开发的非官方 MIT 开源辅助工具。素材数量、大小、格式与模型能力以网页实际限制为准；上传和匹配不等于生成。用户检查完成后自行提交生成任务。

## 上传包选择

优先上传 `jimeng-asset-matcher-skill-v0.3.22.zip`，包内为单个 `jimeng-asset-matcher` 根文件夹。如果上传器要求打开 ZIP 就直接看到 `SKILL.md`，使用同内容的 `jimeng-asset-matcher-skill-v0.3.22-flat.zip`。

平台需要仓库而不是 ZIP 时，将整个 Skill 文件夹放到平台规定的 skills 目录，并填写上表字段。若平台另有插件 manifest、支付配置、封面尺寸或审核字段，需要针对该平台补齐；这些 ZIP 是 Skill 分发包，尚未提交任何市场审核。
