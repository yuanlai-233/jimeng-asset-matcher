v0.3.16 / Chrome / 即梦国内站 / Seedance 2.5 / 全能参考，2026-09-11 实测。

## 正常名称

复制 [prompt.txt](prompt.txt)，点击「自动上传」选择 **images** 文件夹，再「自动匹配」。

| 文件 | 结果 |
| --- | --- |
| `角色 正面.png` | 上传、匹配成功。 |
| `scene morning.png` | 上传、匹配成功。 |
| `道具  背包.png`（两个空格） | 上传、匹配成功；原文双空格保留，原生标签按单空格显示。 |

## 冲突名称

复制 [collision-prompt.txt](collision-prompt.txt)，在一个新测试页点击「自动上传」，选择 **collision** 文件夹。

该目录有 `同名 测试.png`、`同名  测试.png`、`同名测试.png`。其中前两个只有空格数量不同，会规范化为同一个名称。本次网页实测显示「发现 2 个同名文件」，上传已停止。

![空格数量造成的同名冲突在上传前被拦截](../../docs/images/user-guide/15-space-conflict.png)

本地匹配检查也确认：有空格的 `同名 测试` 与无空格的 `同名测试` 仍是不同名称；`@ 角色 正面` 因 `@` 后紧跟空格而被拒绝。这两项为本地代码检查，未另做网页上传。

处理方式：给素材取真正不同的名称，例如 `同名_正面.png`、`同名_侧面.png`，同步修改提示词，再 **Shift + 点击自动上传**重选、重扫。

图片复用了多素材示例的编号卡，仅用于名称校验。所有测试都未提交视频生成任务。
