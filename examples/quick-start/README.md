# 两图入门示例

下载项目后，打开 [prompt.txt](prompt.txt) 复制提示词，在即梦选择 **Seedance 2.5 → 全能参考**。

点击「自动上传」并选择本目录下的 **images 文件夹**，等图片就绪，再点击「自动匹配」。

- [产品_绿杯.png](images/产品_绿杯.png)：产品外观参考。
- [场景_窗边.png](images/场景_窗边.png)：摆放环境参考。

预期结果：2 张图片、2 处原生标签，状态「已匹配」。普通页和无限画布均已实测；未提交视频生成。

两张图片通过内置图像生成工具为本教程制作，没有使用用户私人素材。生成提示词见 [image-prompts.md](image-prompts.md)。
